Seal a brief before work starts

Paste your brief, or choose the file. A chosen file is hashed as raw bytes, which is what seal-benchmark does. Pasted text is hashed as UTF-8 with LF line endings, so a CRLF file gives a different hash.



A browser seal is only as trustworthy as where you publish it. Commit the JSON or post it somewhere timestamped before work starts.
