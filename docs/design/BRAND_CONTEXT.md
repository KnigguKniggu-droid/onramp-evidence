# OnRamp brand-context block

Following Awesmos' guidance, this is a reusable block to prepend to any prompt or design pass for OnRamp pages.

- **Product:** OnRamp, an IBM Bob kit that tells inherited test failures apart from new regressions, and proves fixes test-first.
- **Audience:** hackathon judges and engineers. They scan first, then verify.
- **Voice:** plain, precise, evidence-first. No hype. Every number comes from a file or a commit, and anything synthetic is labelled.
- **Hierarchy:** problem → how it decides → try it → proof (baseline, blind fix, feature, portability) → provenance.
- **Colour roles** (meaning only):
  - amber = inherited / warning / targeted
  - red = regression
  - green = fixed / clean full run
  - purple = not run
  - blue = action / focus
  - grey = unchanged
- **Type:** IBM Plex Sans for UI and IBM Plex Mono for code and evidence. Scale 12/13/14/16 px plus fluid display sizes.
- **Shape:** 12 px containers, pill chips, 8 px on small items.
- **Motion:** every animation explains a state, a flow or an order. Durations 150–300 ms micro, ~500 ms entrances. Pausable, and fades only under reduced motion.
- **Never:** fake metrics, a live-Bob illusion, green for targeted or incomplete runs, emoji icons, lorem ipsum.
